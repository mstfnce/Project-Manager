# Project Manager

Project Manager, ekiplerin ve bireysel geliştiricilerin projelerini, görevlerini ve notlarını tek bir yerden takip edebilmesi için geliştirilen basit bir proje yönetim uygulamasıdır. Kullanıcılar giriş yaptıktan sonra projelerini oluşturabilir, düzenleyebilir, durumlarını (planlama, aktif, tamamlandı vb.) güncelleyebilir ve her projenin görev/not sayısını tek bakışta görebilir. Bu proje, aynı zamanda modern web geliştirme pratiklerini öğrenmek amacıyla adım adım inşa edilen bir öğrenme çalışmasıdır.
